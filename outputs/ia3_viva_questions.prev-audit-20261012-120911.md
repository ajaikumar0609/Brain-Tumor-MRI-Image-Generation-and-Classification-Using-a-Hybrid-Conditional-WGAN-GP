1. **Q: What is the project's goal?** A: Compare DCGAN, WGAN-GP and a conditional WGAN-GP (cWGAN-GP) for 64×64 brain MRI generation using FID/KID, and test whether cWGAN-GP images help a CNN tumour classifier.
2. **Q: What data was used?** A: Kaggle Brain Tumor MRI Dataset, 4 classes. Training 5,600 images (1,400/class), Testing 1,600 (400/class), converted to 64×64 grayscale.
3. **Q: How was Testing used?** A: As the FID/KID real reference and for final classifier evaluation; it was also used earlier for a pretrained-classifier sanity check. No GAN training or selection step used it.
4. **Q: Which GAN was best?** A: DCGAN on both FID (133.8) and KID (0.119). The proposed cWGAN-GP was second (147.3 / 0.135), WGAN-GP last (160.8 / 0.149).
5. **Q: Why report that the proposed model lost?** A: Results must be reported honestly; the data show DCGAN best at this training budget. It is not known whether this would hold with longer training.
6. **Q: What is the WGAN-GP loss?** A: Critic minimises D(fake) − D(real) + λ·GP, with GP the squared deviation of the critic's gradient norm from 1 on interpolates, λ=10 (Gulrajani et al.).
7. **Q: Why does the critic have no BatchNorm?** A: The gradient penalty is per-sample, and BatchNorm couples samples within a batch. Our WGAN-GP critic is BatchNorm-free.
8. **Q: How does cWGAN-GP condition on class?** A: A 50-d label embedding is concatenated to z in the generator, and the critic is a projection critic D(x,y)=ψ(h(x))+⟨E(y),h(x)⟩ (Miyato & Koyama); no classifier guidance.
9. **Q: What are FID and KID?** A: FID is the Fréchet distance between Gaussians fitted to Inception pool3 features (Heusel et al.). KID is an unbiased MMD² with a cubic polynomial kernel on the same features (Binkowski et al.). Lower is better for both.
10. **Q: Why is the real-reference FID 14.1 and not 0?** A: It compares 1,600 real Training images with the 1,600 Testing images, which are different samples. It's a floor reflecting finite-sample and split differences.
11. **Q: How reliable are the FID differences?** A: Across-seed stds (1–2 FID) are much smaller than the gaps between models, but they cover only generation-seed variability; GAN training was run once per model and the reference set has no uncertainty estimate.
12. **Q: What did the per-class analysis show?** A: cWGAN-GP per-class FIDs: glioma 171, meningioma 177, notumor 170, pituitary 198 (worst). Only meningioma's KID was lowest against its own real class.
13. **Q: What does the class-confusion KID matrix show?** A: Generated glioma, notumor and pituitary images are numerically closest to real meningioma, not their own class, with small differences; this is weak evidence for effective conditioning.
14. **Q: Describe the downstream conditions.** A: A: 4,480 real. B: A + 5,600 clean-cWGAN-GP images (10,080). C: the same real images resampled with replacement to 10,080 (2,520/class), 3,998 distinct images drawn, no synthetic.
15. **Q: What were the downstream results?** A: Test accuracy A 0.811 ± 0.047, B 0.852 ± 0.017, C 0.869 ± 0.027 (macro-F1 0.810, 0.847, 0.868), 3 seeds.
16. **Q: Does synthetic augmentation help?** A: No evidence it does. B>A, but C>A by more and B−C is negative in all seeds (mean −0.017), smaller than seed sd; the gain is explained by training-set size and optimizer steps.
17. **Q: Why was Condition C needed?** A: B has more examples and optimizer steps than A, so B>A confounds synthetic content with size. C matches size and steps without synthetic data.
18. **Q: What does C not control for?** A: Diversity. Duplicated real images are exact copies, not new data, whereas synthetic images could add variation or label noise. Only 3 run seeds, one resampling seed and one GAN run; no significance test.
19. **Q: What was the leakage problem?** A: The first cWGAN-GP was trained on all 5,600 Training images, including the 1,120 CNN-validation images used for epoch selection, so synthetic data could carry validation information. That run is preliminary and not used for conclusions.
20. **Q: How was it fixed and how much did it matter?** A: A clean cWGAN-GP was trained only on the 4,480 CNN-training images (audit: 0 overlap with validation, never saw Testing). Leaky B scored 0.869 vs clean B 0.852 (mean gain over A +0.058 vs +0.040).
21. **Q: Is the clean run perfectly leak-free?** A: File-level yes, but 44 of 1,120 validation images (3.9%) are byte-identical to training images (dataset duplicates), so validation accuracy and epoch selection are slightly optimistic. There were 0 byte-identical Training/Testing images, so test accuracy is unaffected; near-duplicates were not checked.
22. **Q: What was the non-finite-loss incident?** A: In the first clean run, seed 44 real+synthetic raised a non-finite-loss error after a Metal "Internal Error" on the M4 GPU and a Mac restart; the cause was not established. The experiment was rerun from scratch with identical settings, finished with finite losses, and reproduced earlier numbers exactly where comparable.
23. **Q: Validation vs test metrics?** A: Validation (real-only, n=1,120) only picks the best epoch; headline accuracies are test accuracies (n=1,600) of that epoch.
24. **Q: Which class was hardest downstream?** A: Glioma: lowest recall (A 0.665, B 0.628, C 0.767), frequently confused with meningioma. B's glioma F1 (0.749) was below A's (0.772).
25. **Q: Can this be used clinically?** A: No. Generated images are not shown to contain anatomically accurate tumours; synthetic labels are unverified; the classifier is a small research model.
26. **Q: What does the EfficientNet-B3 score of 95.94% mean?** A: Only a sanity check of the data; that model may overlap its original training data, so it is not an independent benchmark.
27. **Q: Main limitations and future work?** A: Short 3,000-update training, few seeds, single GAN runs, 64×64 grayscale, ImageNet-based metrics. Future: longer training, more seeds, label-correctness checks, significance tests.
